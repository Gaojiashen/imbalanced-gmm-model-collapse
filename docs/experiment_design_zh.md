# GAOJiashen 的不均衡 GMM 实验设置

本部分研究：与等权重真实 GMM 相比，真实分布中存在稀有分量时，递归训练的退化方式是否改变，稀有峰是否更容易失去覆盖。

## 固定真实分布

配置文件为 `gao_unbalanced_true_gmm.json`，完整保存 25 个权重、中心和协方差矩阵。它是人为指定的真实分布，不是拟合结果。

沿用组员实际设置：二维、25 个分量、中心为 `{-2,-1,0,1,2} × {-2,-1,0,1,2}`、每个分量协方差为 `0.01 I`、标准差为 0.1。只改变混合权重，不使用此前讨论中的间距 2 或标准差 0.2。

| 分组 | 个数 | 每个分量权重 | 合计 |
| --- | ---: | ---: | ---: |
| 稀有分量 | 5 | 1% | 5% |
| 常见分量 | 20 | 4.75% | 95% |

本次选定的稀有中心是 `(-2,-2)、(-1,-1)、(0,0)、(1,1)、(2,2)`。按照组员源代码的数组顺序，零基索引为 `[0,6,12,18,24]`，一基编号为 `[1,7,13,19,25]`。这一位置安排是本次设计选择，不是老师规定或组员原设置；实验期间固定，不能根据结果挑选位置。

真实整体均值为 `[0,0]`，整体协方差为 `[[2.01,-0.375],[-0.375,2.01]]`，总方差（迹）为 4.02。改变权重会改变整体协方差；每个分量内部的协方差仍然是 `0.01 I`。本设置总方差与等权重基线相同，并不意味着两个分布相同。

## 与组员保持一致的实验条件

| 条件 | 约定值 |
| --- | --- |
| 学习模型 | 二维、25 分量、完整协方差 GMM |
| 首代真实训练样本量 | 2000 |
| 后续每代训练总样本量 | 2000 |
| 训练代数 | 2000；先用短运行检查程序 |
| 随机种子 | 0、1、2、3、4 |
| EM 初始化次数 | 3 |
| 初始化方法 | greedy k-means++，每步 5 个候选，Lloyd 最多 100 次 |
| EM 最大迭代数 | 300 |
| 收敛容差 | 1e-4 |
| 协方差正则项 | 1e-6 I |
| 每代初始化 | 从当前训练样本重新初始化 |
| 数值精度 | float64 |
| 采样偏置 | 无，lambda=1 |
| 独立真实评估样本量 | 每个种子固定 5000 |
| 每次生成评估样本量 | 5000 |
| 评估频率 | 每 20 代，以及第 1、200、2000 代 |

每代 2000 个真实样本时，每个稀有分量的期望样本数为 20，常见分量为 95。这只是期望；必须按权重随机抽取分量，不能强制每个分量恰好出现这些样本数。

拟合时所有 25 个权重、中心和协方差都由当前样本估计，不将真实的 1%/4.75% 权重、中心或协方差强制写入学习模型。真实参数仅用于生成真实数据和评估。

## 分别运行的三种条件

第一代全部用 2000 个真实样本拟合。第二代起：

| 条件 | 每代新鲜真实样本 | 上一代模型生成样本 |
| --- | ---: | ---: |
| 全合成 | 0 | 2000 |
| 10% 新鲜真实数据 | 200 | 1800 |
| 100% 新鲜真实数据对照 | 2000 | 0 |

每个条件使用本文件定义的不均衡真实 GMM。各条件中的新鲜样本每代独立重新抽取，评估集不用于训练，合成数据不累积历代样本。同一个种子下三条件应使用相同首代真实训练数据，便于对照。

这份文件只准备分布配置和实验约定。组员当前的 `target_parameters()` 把权重写死为等权重；后续运行代码必须显式读取本配置，而不是仅把这个文件放在目录中就认为分布已经更改。

## 指标与分析重点

沿用组员的总方差、平均分量内方差、加权分量内方差、Recall（k=5）、真实评估数据 NLL 和真实峰邻域覆盖数。覆盖半径保持 `4 * std = 0.4`，以便直接对照。

另将 25 个真实峰的覆盖情况按上述固定索引分为两组，记录“稀有峰覆盖数 / 5”和“常见峰覆盖数 / 20”；同时记录各真实中心邻域的生成概率质量。比较覆盖比例而非直接比较两组丢失峰的个数。

整体 Recall 和 NLL 按真实数据分布加权，稀有分量只占 5%，其丢失可能在整体指标上不显著，因此需要单独的逐峰结果。

观察首代拟合质量，完整保留各种子的结果。稀有峰是否更容易丢失是待验证的问题，不能预先当成实验结论；收敛失败、协方差正则化和初始化效果都应与代际退化区分。

最终对照组员的均衡实验与自己的不均衡实验。每条轨迹先与各自真实分布及首代模型比较，双方统一图表坐标、采样量和指标定义。
