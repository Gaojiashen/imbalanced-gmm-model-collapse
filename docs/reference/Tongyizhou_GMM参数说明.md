# Tongyizhou 实验的 GMM 参数提取

提取日期：2026 年 11 月 16 日。参数来自实际代码及 `results` 中保存的配置，未运行训练，也未修改组员文件。

## 1 固定真实分布

该实验使用二维、25 分量、等权重的高斯混合分布：

$$
p_{\mathrm{true}}(x)=\frac{1}{25}\sum_{a=-2}^2\sum_{b=-2}^2
\mathcal N\!\left(x;\begin{bmatrix}a\\b\end{bmatrix},0.01I_2\right).
$$

| 参数 | 提取值 |
| --- | --- |
| 维数 | 2 |
| 高斯分量数 | 25 |
| 分量中心 | `{-2,-1,0,1,2} × {-2,-1,0,1,2}` |
| 相邻网格中心距离 | 1 |
| 每个分量权重 | `1/25 = 0.04` |
| 每个方向的标准差 | `0.1` |
| 每个方向的方差 | `0.01` |
| 每个分量的协方差矩阵 | `[[0.01, 0], [0, 0.01]]` |
| 真实整体均值（推导值） | `[0, 0]` |
| 真实整体协方差（推导值） | `[[2.01, 0], [0, 2.01]]` |
| 真实总方差，即整体协方差的迹（推导值） | `4.02` |

注意，`0.01 I` 是每个高斯分量内部的协方差，`2.01 I` 是包含分量中心差异后的整个混合分布协方差。`reg_covar=1e-6` 是训练的数值正则项，不是真实分布方差。

这与先前讨论的建议设置不同：组员实际采用网格间距 1、标准差 0.1；本次原样提取，没有改成间距 2、标准差 0.2，也没有改为稀有分量版本。

## 2 学习模型的拟合设置

真实 GMM 固定不变；每代被训练的 GMM 都重新从当前数据估计参数。拟合模型同样是二维、25 分量，但学习完整协方差矩阵，不强制拟合结果保持各向同性或等权重。

| 设置 | 值 |
| --- | --- |
| 拟合方法 | 自定义 PyTorch CUDA EM |
| 每代独立初始化次数 | 3 |
| 初始化策略 | greedy k-means++，每次选中心考察 5 个候选 |
| 初始化中的 Lloyd 更新上限 | 100 |
| EM 迭代上限 | 300 |
| 收敛容差 | `1e-4`，平均训练对数似然变化的绝对值 |
| 协方差正则项 | `1e-6 I` |
| 初始化选择标准 | 最终平均训练对数似然最高 |
| 每代是否重新初始化 | 是 |
| 数值精度 | float64 |
| 合成采样偏置 | 无，等价于论文记号 `lambda=1` |

EM 使用最大似然协方差更新，加上正则项；不能直接当成论文第 3.1 节采用分母 n−1 的无偏样本协方差更新。

## 3 已保存的实验配置

三组主要实验共享相同真实分布、拟合配置、2000 代及随机种子 `0,1,2,3,4`。第一代均使用 2000 个真实样本。从第二代开始：

| 目录 | 每代新鲜真实样本 | 每代上一代合成样本 | 总样本 |
| --- | ---: | ---: | ---: |
| `results/gmm` | 0 | 2000 | 2000 |
| `results/gmm_fresh10` | 200 | 1800 | 2000 |
| `results/gmm_fresh100` | 2000 | 0 | 2000 |

新鲜真实样本每代独立重新抽取；没有复用同一批真实样本的固定真实数据循环。合成样本只来自上一代，未累积全部历史合成样本。按混合权重独立选择分量，不强制每个峰抽到相同数量。

`results/gmm/config.json` 没有记录 `fresh_fraction` 字段；这里的 0 来自项目说明及当前脚本默认值。其余两组配置分别明确记录 0.1 和 1.0。

另有 `results/gmm_single_candidate` 历史实验。其参数与当前真实分布相同，但使用过不同的初始化策略；旧配置保留在实验设置 JSON 中，不将当前初始化方法追溯套用。

## 4 评估设置

- 每个种子固定 5000 个独立真实参考点，只用于评估。
- 每次评估另抽 5000 个生成点。
- 每 20 代，以及第 1、200、2000 代评估。
- Recall 使用 `k=5`。
- 原始峰覆盖以距最近真实中心 `4 × 0.1 = 0.4` 以内且至少存在一个生成点为准。这是组员实现的额外诊断定义，不等同于 Recall。
- 保存总体方差、平均分量内方差、加权分量内方差、Recall、真实数据 NLL、原始峰覆盖数。
- 初始训练、拟合初始化、真实参考采样、生成评估、新鲜真实采样采用独立随机流。

## 5 输出文件及来源

- `tongyizhou_true_gmm.json`：完整的 weights、means、covariances 数组，可直接作为后续数据生成配置读取；它不是某代训练结果。
- `tongyizhou_experiment_settings.json`：实际运行配置、拟合与评估设置、三种训练组成和历史实验说明。
- 本说明：便于人工阅读和对照。

核对来源：

- `Tongyizhou/reproduce_gmm.py` 第 50–53 行：真实参数构造。
- `Tongyizhou/results/gmm/config.json` 及两个 fresh 实验的 `config.json`：实际运行数值。
- `Tongyizhou/gmm_cuda.py`：25 分量完整协方差 EM、初始化、采样及 Recall 的实现。
- `Tongyizhou/PROJECT.md`：实验条件及旧初始化版本的解释。

每代实际拟合出来的参数仍保存在原目录 `Tongyizhou/results/<实验>/seed_<种子>/parameters.npz` 中，含 weights、means、covariances 等数组。本次提取配置，没有复制完整训练轨迹。
